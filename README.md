# VEDA Technology – Task 9: Descriptive Statistics Primer

## 📌 Overview

This project focuses on performing descriptive statistical analysis on the Iris dataset. The objective is to summarize the main characteristics of the dataset using statistical measures and interpret the distribution and variability of the numeric variables.

The analysis was performed using Microsoft Excel.

## 🎯 Objective

The main objectives of this task are to:

- Calculate key descriptive statistics for numeric variables.
- Understand the central tendency of the data.
- Measure the spread and variability of the observations.
- Compare mean and median values to identify possible skewness.
- Interpret the statistical results in a clear and meaningful way.
- Present the findings using tables and data visualization.

## 📊 Dataset

**Dataset:** Iris Dataset

The analysis includes the following numeric variables:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

The `Species` column is categorical and was therefore excluded from the numerical statistical calculations.

## 🛠️ Tools Used

- Microsoft Excel
- GitHub

## 📈 Descriptive Statistics Performed

The following statistical measures were calculated:

- Count
- Mean
- Median
- Mode
- Standard Deviation
- Minimum
- 25th Percentile (Q1)
- 50th Percentile (Median)
- 75th Percentile (Q3)
- Maximum
- Interquartile Range (IQR)

### Interquartile Range

The IQR was calculated using:

**IQR = Q3 − Q1**

It represents the spread of the middle 50% of observations.

## 🔍 Key Findings

- **Sepal Length:** The mean and median are very close, indicating limited apparent skewness. The variable shows moderate overall variation.
- **Sepal Width:** The mean and median are also close, suggesting limited apparent skewness and relatively lower variation compared with the other variables.
- **Petal Length:** The mean is lower than the median, indicating a tendency toward negative skew in the combined dataset. It also has the largest standard deviation and IQR among the analyzed variables.
- **Petal Width:** The mean is slightly lower than the median, indicating a slight tendency toward negative skew and noticeable variation.
